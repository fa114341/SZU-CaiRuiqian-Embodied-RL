# UFO / T800 基础动作

把 T800 接入 UFO 的 FB/TeCH 动作学习流程，曾进行单动作前进 50M 环境步、多动作训练及约 55M 环境步续训。实验有 checkpoint 和视频评估，但前进语义常表现为后退、小碎步或跟踪失败。讨论过专家轨迹坐标、初始化/相位、latent 路由、动力学配置及方向/速度奖励；目前不能仅凭奖励曲线认定动作语义正确。

服务器完整 checkpoint 含模型和优化器，体积远超普通 Git 文件限制。本仓库暂记录模型索引，不把仅有的路径当作备份完成。包含 LAFAN1 来源或改编动作的训练数据/视频暂不公开。
