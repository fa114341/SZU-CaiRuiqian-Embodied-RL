# T800 直立行走修复设计

## 目标

修复 G1→T800 重定向中逐渐累积的根姿态倾斜，避免 SMP prior 和 PPO 把过度前倾当作正常步态；在不破坏已验证的 25 个 T800 关节映射的前提下重新产出直立行走策略。

## 已确认根因

- GMR 输出的根四元数相对 SMP G1 基线发生明显漂移。例如 `walk3_subject5` 的俯仰中位数由 16.6° 变为 56.6°，`walk4_subject1` 由 14.4° 变为 57.2°。
- 85% 限位只约束 25 个受控关节，不约束自由根关节，因此旧验证无法发现整体前倾。
- PPO 速度指令为 0.5–5.0 m/s，而训练数据速度中位数约 0.73 m/s、95% 分位约 1.97 m/s，过高指令会进一步鼓励前倾。

## 方案选择（根据探针视频复审后更新）

1. **采用：整段质量筛选。** 不使用根姿态覆盖探针；从未经根姿态二次修改的原始 GMR 输出中，仅保留整段倾角统计合格的 5 条数据：`walk1_subject1`、`walk1_subject2`、`walk1_subject5`、`walk3_subject1`、`walk3_subject2`。
2. G1 根姿态覆盖探针。数值上消除了旋转漂移，但根旋转与根高度不再耦合，造成脚底悬空，因此拒绝进入训练。
3. 调整官方 GMR IK 的根旋转与根位置联合映射。技术上更完整，但超出本轮快速跑通 SMP→T800 基线的必要范围，保留为后续改进。

## 数据链路

原始 BVH → 官方 GMR 求解 T800 根位置与 25 关节 → 31 帧平滑 → 85% 关节限位 → 整段姿态质量筛选 → 5 条干净 CSV→NPZ → SMP prior → PPO。

PPO 速度命令范围改为 0.5–2.0 m/s，与数据的 95% 速度范围一致。

## 验收标准

- 精确保留 5 个批准文件，不混入根姿态覆盖探针。
- 每条保留数据的绝对俯仰角中位数低于 20°，超过 30° 的帧比例低于 10%。
- 四元数单位范数误差不超过 1e-6，符号连续。
- 25 个关节在 T800 官方 85% 安全区间内，硬限位和软限位越界均为 0。
- 最终策略视频中躯干保持接近干净参考数据姿态，双脚没有因根姿态二次覆盖而整体悬空，也不通过持续前倾追逐超出数据范围的目标速度。

## 失败处理

任何入选文件若不满足倾角、脚底视觉或关节限位门槛，整段排除，不做局部根姿态补丁；数据门槛未通过时不启动 prior/PPO。
