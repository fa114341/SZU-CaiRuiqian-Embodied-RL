# G1 NPZ Two-Lateral Motions to T800 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the two official G1 side-walk NPZs into validated T800 CSV/NPZ references and replay videos without starting PPO.

**Architecture:** A self-contained converter in the isolated PAC-MAN T800 worktree reads the fixed G1 body order, normalizes heading, constructs T800 task-space targets from source motion deltas, and solves sequential Mink IK with guarded joint limits. Existing PAC-MAN CSV-to-NPZ grounding/FK and replay tools produce the final training-format references and evidence.

**Tech Stack:** Python 3.11, NumPy, SciPy, MuJoCo, Mink, MjLab, pytest, ffmpeg/OpenCV.
