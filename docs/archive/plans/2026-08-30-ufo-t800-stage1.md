# UFO T800 Stage 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish the minimal verified UFO pipeline from the official G1 smoke test through T800 robot/data configuration, T800 UFO-FB smoke training, and one inference video.

**Architecture:** Keep the upstream UFO checkout clean and create a linked worktree for T800-specific changes. Reuse the authoritative EngineAI T800 MuJoCo/URDF assets and an already validated GMR-direct T800 RobotState CSV; validate joint/action order before training. Run only smoke-scale jobs on the single RTX 5090 and keep all logs and outputs under an isolated stage directory.

**Tech Stack:** UFO, mjlab, MuJoCo, PyTorch, uv, Hydra, pytest, GMR RobotState CSV, tmux, RTX 5090.

**Execution status (2026-08-30):** Stage 1 is complete. The official G1 and
T800 real-update probes both exited zero at `global_time=12288` with
`optimizer_steps=32`; the final direct-Python suite passed 97 tests. T800
tracking inference produced a complete 300-frame MP4, but the smoke-scale policy
fell at about 0.67 seconds, so the pipeline gate passed while the motion-quality
gate failed. Use the exact evidence and next-stage limitation recorded in
`T800_CONTEXT.md` section 27. On RTX 5090, use the environment Python directly
with the complete cu128 dependency stack; do not use `uv run`, which restores
the locked cu126 stack.
